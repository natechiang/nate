🐋 The Whale's Lost Treasure — Markers

Print this page and cut out the markers. Attach each one to its matching object around the house.

Setup Instructions

  1. Memory 1 — Curiosity: Attach to a book, journal, puzzle, or map.
  2. Memory 2 — Courage: Attach to a swim medal, award, sports ribbon, or challenge item.
  3. Memory 3 — Adventure: Attach to a travel souvenir, shell, vacation item, or postcard.
  4. Memory 4 — Love: Attach to a recipe book, favorite mug, or something closely associated with Mom.
  5. Memory 5 — Family: Attach to a family keepsake, ornament, wedding item, or memory box.

Each marker must be found in order. The website will only accept them in sequence.
